# Finn — Minhas finanças

App de finanças pessoais que roda no navegador. Os dados ficam salvos **só no aparelho** (localStorage) — nada é enviado pra servidor nenhum.

**Usar no iPhone:** abra o link no Safari → Compartilhar → *Adicionar à Tela de Início*.

Faça backup em **Ajustes → Backup** de vez em quando.
